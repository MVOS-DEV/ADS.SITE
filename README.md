M.V.O.S. (Meu Vovô Odeia Sujeira)

Bem-vindo ao repositório oficial do M.V.O.S., um jogo de suspense e sobrevivência desenvolvido em Construct 3.

    "O silêncio do campo foi rompido por algo que não pertence a este mundo. Quando uma substância viscosa e radioativa começa a transformar a fauna local em aberrações agressivas, Arthur decide que não vai a lugar algum. Ele se torna a última barreira entre o seu lar e uma infestação que ameaça consumir tudo."

🎮 Sobre o Jogo

M.V.O.S. é um jogo de terror/suspense com temática trash e mecânicas de defesa de território. Você assume o papel de um idoso rabugento em um confronto direto contra animais mutantes infeccionados por uma substância misteriosa.

    Gênero: Suspense / Shooter (Top-Down)

    Engine: Construct 3

    Plataforma: Web / PC

    Status: 🚧 Protótipo em desenvolvimento

🚀 Como Jogar

O jogo foi projetado para rodar diretamente no navegador ou via executável.

    Acesse a versão Web: https://github.com/MVOS-DEV/ADS.SITE


⚙️ Tecnologias Utilizadas

    Engine: Construct 3

    Arte: Estilo Pixel Art personalizado.

    Ferramentas de Desenvolvimento: Cursor (IA de auxílio), editores de imagem para tratamento de assets.
